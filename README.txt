NIGHTON 전용 홍보페이지 예시

1) share.html과 images 폴더를 기존 NIGHTON 프로젝트 루트에 업로드합니다.
2) 배포 후 예시 주소:
   https://nighton.kr/share.html?src=instagram
   https://nighton.kr/share.html?src=kakao
   https://nighton.kr/share.html?src=job_a
3) 사용자가 홍보 이미지 또는 CTA 버튼을 누르면:
   https://nighton.kr/?src=instagram
   처럼 원래 NIGHTON 메인으로 이동합니다.
4) 모바일/PC 반응형이며, 이미지 전체가 클릭/터치 영역입니다.
